# CLAUDE.md — Spanish Ladder

Guidance for Claude Code. Read `PRD.md` (what) and `DESIGN.md` (look). This file covers how to build it.

---

## 1. What this is
A static, levelled Spanish course for Indonesian speakers, A1 → C1 (CEFR/DELE, checked against PCIC). It's the fifth app in the Ladder monorepo, `apps/spanish`, on `packages/ladder-core`.

v1 ships Dasar (optional), Easy 1 and Easy 2 with placement, the A1 deck, seven visuals and audio. It deploys to the `spanish-ladder` repo's Pages.

---

## 2. Starting point
1. Read `README.md`, `docs/ladder-core-report.md`, `docs/migrate-arabic.md`, `docs/migrate-mandarin.md`, the Japanese plan and report, and `docs/DEPLOY.md`. Core has grown with each app; use what exists.
2. **Start from `apps/english`, not from Japanese or Mandarin.** Spanish is Latin script and left to right, so English's text components and content adapter are the right base. Copy `apps/english` to `apps/spanish`, delete content and the English visuals, and keep the PlaceScene drawing.
3. Write `apps/spanish/course.config.ts`:
   - `target: { lang: 'es', dir: 'ltr' }`
   - storage key `spanish-ladder:v1`, cache prefix `spanish-ladder-`
   - Spanish text hooks (§5.1), voice scorer (§5.4), lint (§4)
   - explanation languages `id` / `es` with the rung fade
   - Azulejo as `boardPattern`; ladder chip = CEFR/DELE
   - all `fixes.*` on
4. Set `theme.css` (DESIGN §3); replace the manifest, icons, metadata and About copy.
5. **Engine changes go into core, behind config.** Spanish should need very few. Likely candidates:
   - an `accentBar` input helper (generic: any Latin-script language with diacritics)
   - lenient-accent grading as a generic grading option
   - a `variety` strand mechanism, if Arabic's Egyptian card isn't already generic
6. After every core change, the parity screenshots of all four existing apps must still match exactly.

## 3. Content model

### 3.1 Curriculum
`content/curriculum.yaml` holds all ten rungs:
- `tier: dasar | easy | medium | hard`
- `cefr`, `dele`
- `explain_lang: id | mixed | es`
- `lessons`, `words_target`
- `inventory` (grammar ids from `content/data/grammar.yaml`, each tagged with its PCIC level)

### 3.2 Lesson
```yaml
id: easy1-07-ser-estar
rung: easy-1
order: 7
status: draft
review: { by: "Profesora …", date: 2026-12-01 }   # required when reviewed
minutes: 8
title: { id: "Ser atau estar?", en: "Ser or estar?", es: "¿Ser o estar?" }
summary: { id: "...", en: "..." }
introduces: [a1-ser-estar-contrast]
spiral: ser-estar
visual: { id: ser-estar, props: { set: basic } }
examples:
  - es: "Lucía [[es]] de Bogotá."
    id: "Lucía berasal dari Bogotá."
  - es: "Lucía [[está]] en Madrid."
    id: "Lucía sedang di Madrid."
    es_es: "Lucía [[está]] en Madrid."      # only when Spain differs
pair:
  off: "Yo soy cansado."
  natural: "Yo [[estoy]] cansado."
sound:  { words: ["pero", "perro"], tip: { id, en } }
spain:  { rows: [{ latam: "¿Dónde está el carro?", es: "¿Dónde está el coche?" }], note: { id, en } }
words:  { id: "...", en: "..." }                    # Kata card (bridges, false friends)
talk:   { lines: [{ who, es, id }] }
tirukan: { es: "...", id: "..." }
check: [ ...4–6 items ]
glossary:
  - { es: "cansado", id: "lelah", pos: adj, forms: [cansado, cansada, cansados, cansadas] }
  - { es: "mesa", id: "meja", pos: noun, gender: f, plural: mesas, bridge: { pt: mesa, id: meja } }
  - { es: "tener", id: "punya", pos: verb, verb: { group: er, irregular: true } }
next: easy1-08-hay
```

### 3.3 Check items
The siblings' types, plus:

| type | fields |
|---|---|
| `form` | `base` (lemma or base phrase), `target` (e.g. `{ person: yo, tense: presente }` or `{ gender: f, number: pl }`), `answer`, `accept?`, `accents?: strict | lenient` |
| `conjugate` | `verb`, `tense`, `persons` (subset), `answers` (map) |
| `agree` | `noun` (with gender/number), `slots` (article, adjective), `options`, `answers` |
| `dictation` | `audio` (text), `answer`, `accents?` |
| `stress` | `word`, `syllables`, `stressed` (index), `needsAccent` |

**Accents** default to `lenient` before Easy 3 and `strict` from Easy 3 on. `stress` items are always strict.

### 3.4 Data
- `content/data/grammar.yaml`: grammar points with ids, PCIC level, and short descriptions. Authored from the PCIC inventories (cite the PCIC section per item) and checked by the reviewer.
- `content/data/verbs.yaml`: verbs used up to the live rungs, with irregular forms per tense listed explicitly. Regular forms are generated by `lib/es/conjugate.ts` and **tested against the listed forms**.
- `content/data/bridges.yaml`: Indonesian ↔ Portuguese ↔ Spanish bridges and false friends, each reviewed.
- **Deck lists:** a frequency list from an openly licensed corpus, tagged to levels by PCIC vocabulary notions. Record the source and licence in `content/data/vendor/SOURCE.md`, and label the level tags as estimates.

## 4. Content and accuracy rules
1. **Inventory.** Grammar from earlier rungs plus this rung up to this lesson. Words on the rung's list or below, or in `extra:` with a reason. Lint detectors cover:
   - past tenses before Easy 3
   - subjunctive forms before Medium 2
   - *vosotros* forms produced (not just shown) before Hard 2
   - object pronoun clusters (se lo) before Medium 1
2. **Variety.**
   - `es` lines are neutral Latin American (ustedes, Latin American vocabulary).
   - `es_es` appears only where Spain really differs.
   - Never mix varieties within one line.
3. **Spelling.**
   - Every `es` string uses correct accents and opening ¿ ¡.
   - Lint checks words against the lexicon and Hunspell-style accent rules: word stress classes, and *qué/que*, *él/el*, *tú/tu*, *sí/si* by context where detectable.
4. **Conjugations** in content must match `lib/es/conjugate.ts` + `verbs.yaml`. Lint errors on any mismatch.
5. **Agreement:** lint checks article–noun–adjective agreement in simple noun phrases, using glossary gender and number.
6. **Bridges and false friends** come from `bridges.yaml` only.
7. **Register:** examples addressed to the learner use *tú* until Easy 2 lesson 1, then mix *tú* and *usted* as the situation calls for. The Indonesian translation matches the register.
8. **Content:** everyday and work situations across the Spanish-speaking world; no politics; no clichés.
9. **Reviews:**
   - Claude drafts with `status: draft` and never sets `reviewed` or fills `review`.
   - Reviewed lessons need `review.by` and `review.date`.
   - España cards need a Spain-speaker review noted in `review.es_by`.
10. **Sizes:** as English Ladder (4–6 examples, 4–6 checks, 6–12 glossary words).
11. **Ids are permanent.**

## 5. Architecture

### 5.1 `lib/es/` (pure, tested)

| Function | Purpose |
|---|---|
| `normEs(s, { accents })` | NFC; lowercase; strip opening ¿ ¡ and trailing punctuation; with `accents: 'lenient'`, also fold á→a, é→e, í→i, ó→o, ú→u (ñ and ü stay distinct) |
| `accentDiff(given, expected)` | Report whether the only difference is accents (drives the "Hampir sempurna" note) |
| `syllabify(word)` | Spanish syllabification (diphthongs, hiatus, *qu*, *gu*, *ll*, *rr*, *ch*) |
| `stressOf(word)` | Index of the stressed syllable from written accent or default rules |
| `needsAccent(word, stressedIdx)` | Aguda/llana/esdrújula rule |
| `conjugate(verb, tense, person)` | Regular -ar/-er/-ir patterns, stem changes (e→ie, o→ue, e→i, u→ue), orthographic changes (c→qu, g→gu, z→c, g→j), with irregular overrides from `verbs.yaml` |
| `agreeAdj(adj, gender, number)` | Adjective forms (-o/-a, invariable -e/-consonant, -ista, -or/-ora) with overrides |
| `article(gender, number, definite)` | Including *el agua* (feminine noun starting with stressed *a*), from a lexicon flag |

### 5.2 Grading
- Core grading with `compare = normEs(…, { accents })`. A lenient pass where `accentDiff` is true returns `{ correct: true, note: 'accent' }`.
- `conjugate` and `agree` items grade per cell.

### 5.3 Accent bar
A generic core component, `AccentBar`, configured per course with its key list. It inserts at the selection of the focused input, has buttons with accessible names, and is shown under every text input in Spanish.

### 5.4 Speech
- **Voice scorer:** `es-MX` > `es-US` > `es-419` > `es-*` (excluding `es-ES`) for Latin American lines; `es-ES` for `es_es` lines and when the `variety` setting is `es`. Prefer neural/natural voices, penalise novelty voices, respect gender.
- **Recordings:** Dasar pairs and Tirukan through the shared manifest; everything else browser voice.

### 5.5 Visuals (in `apps/spanish/visuals`)
StressMap, Agreement, SerEstar, ConjugationGrid, GustarFlip, PlaceSceneEs (wrapping the shared drawing), RoutineClock. Each uses `lib/es` for its logic. None hard-codes forms that the library generates.

### 5.6 Theme, SW, i18n
- **Theme:** `theme.css` per DESIGN §3, `theme-color` from the app theme, and a contrast test.
- **SW:** cache prefix `spanish-ladder-`; precache the shell, `rung/dasar/`, `rung/easy-1/`, `rung/easy-2/`, `placement/`, `words/`.
- **i18n:** app overrides for brand, doors, España card, accent bar, CEFR/DELE labels.

## 6. Testing
Sibling tests, plus:
- **`lib/es`:**
  - `syllabify` on 200 words incl. diphthong and hiatus cases (país, ciudad, guerra, pingüino)
  - `stressOf` and `needsAccent` on 150 words
  - `conjugate` for every verb in `verbs.yaml` across taught tenses, compared with the listed forms
  - `agreeAdj` and `article` (el agua, las aguas)
  - `normEs` with lenient and strict accents
- **Content:** conjugation and agreement lint, accent lint, variety separation.
- **Component:** AccentBar inserts at the cursor; ConjugationGrid table semantics; SerEstar keyboard path; lenient-accent note on the feedback sheet.
- **Fonts:** a glyph coverage test for the Spanish set in all three faces.
- **E2E:** door 1 → Easy 1 lesson 1; door 2 → seeded placement → Easy 2; a `conjugate` item; a lenient-accent answer.
- **Parity:** all four sibling apps still match after every core change.
- **Accessibility:** axe on all routes, both themes.

## 7. Build order
1. **M0 App scaffold** from `apps/english`; config; theme; brand.
2. **M1 `lib/es`** with tests; `verbs.yaml`; grammar inventory from PCIC.
3. **M2 Content pipeline:** schema, lint (§4), curriculum with ten rungs.
4. **M3 Core additions:** AccentBar and lenient grading in core; the variety strand, if needed.
5. **M4 Shell:** Azulejo, two doors, Dasar tier, CEFR/DELE chips, strand cards, Tirukan.
6. **M5 Check engine:** `form`, `conjugate`, `agree`, `dictation`, `stress`; placement.
7. **M6 Visuals:** StressMap, Agreement, SerEstar, ConjugationGrid, GustarFlip, PlaceSceneEs, RoutineClock.
8. **M7 Content:** Dasar (6), Easy 1 (12), Easy 2 (12), test pools, placement pool, readings, dialogues, A1 deck.
9. **M8 Audio:** recordings manifest for Dasar pairs and Tirukan; voice scorer.
10. **M9 Polish:** reduced motion, axe, Lighthouse ≥ 95, DESIGN §13 checklist. **Release v1.0.**

## 8. Definition of done
Sibling definition, plus:
- Glyph coverage passes.
- Every conjugation and agreement in content matches the library.
- `lang` attributes are correct (`es-419` / `es-ES` / `id`).
- `content:check` is clean, including reviewer fields.
- All sibling parity screenshots match.

---

## 9. Don't
The siblings' list, plus:
- Don't fork core code into `apps/spanish`.
- Don't hand-write conjugation tables in components; use `lib/es`.
- Don't mix Latin American and Spain forms in one line.
- Don't strip ¿ ¡ from displayed content.
- Don't use blue/pink for gender, or flags for language.
- Don't set `status: reviewed`.
